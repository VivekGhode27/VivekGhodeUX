# Vivek Ghode — Product Designer portfolio

This folder is ready to upload to a GitHub repository and connect to Vercel.

## Publish from GitHub

1. Create a new GitHub repository (for example, `vivek-portfolio`).
2. Upload the **contents of this folder** to the repository root: `dist/`, `vercel.json`, and `README.md`. Do not upload a ZIP as a single file.
3. In Vercel, choose **Add New → Project**, import that GitHub repository, and deploy. The included `vercel.json` selects the static `dist` folder; no build command, environment variables, or sign-in feature is needed.
4. Future changes to the GitHub repository's production branch will trigger a new Vercel deployment.

The homepage is `dist/index.html`. Case-study pages are `dist/redsling.html`, `dist/crickeroo.html`, and `dist/houzeo.html`. Keep the `dist/assets/` folder alongside them so images load.

This copy is separate from the currently live ChatGPT Site. Connecting GitHub to Vercel will create a Vercel URL; it will not automatically replace the existing Site URL.
